# ArcGrid / Page Cache (실험 빌드 1.4.3-r2)

이 소스는 Tachimanga에 설치하는 Tachiyomi 호환 확장 APK를 만드는 프로젝트입니다. ZIP 자체는 확장으로 설치할 수 없습니다.

## 이번 단계에서 구현한 것

- 예제 작품 한 개를 테스트 목록에 표시합니다.
- `005.bookkor.com` 작품 상세 페이지에서 확인할 수 있는 회차 링크를 읽고, **사용자가 제공한 1화 링크를 반드시 포함**하고, 2화는 사이트의 실제 링크가 발견되는 경우에만 추가합니다.
- 각 회차 페이지의 HTML을 받아 본문으로 추정되는 영역을 추출합니다.
- Android `Bitmap`/`Canvas`/`StaticLayout`을 사용하지 않고, 미리 만들어 놓은 한글 비트맵 글리프와 직접 작성한 1비트 PNG 인코더를 통해 실시간 이미지 페이지를 생성합니다.
- 기존 성공 버전과 동일한 방식으로 이미지 URL을 가로채 반환합니다.
- 별도의 서버, API 키, 이미지 렌더링 프록시가 필요 없습니다.

## 주의: 아직 작동이 확인되지 않은 부분

- 이 작업 환경에서는 원격 Bookkor HTML을 원본 그대로 내려받을 수 없고 Android SDK도 없으므로, **전체 APK 빌드 및 iPhone/Tachimanga 런타임 테스트는 완료하지 못했습니다.**
- PNG 생성 코드는 **로컬 JVM에서 직접 컴파일 후 실행**했으며, 결과 PNG가 표준 PNG로 열리는 것까지 확인했습니다.
- 실제 웹페이지 DOM과 HTML 셀렉터가 맞지 않으면 `Chapter body not found`가 발생합니다. 이 경우 사용자가 HTML 구조나 스크린샷을 공유해주면 셀렉터를 조정해야 합니다.
- 목록은 전체 작품 검색이 아니라 **예제 작품 하나**만 제공합니다. 회차 목록은 사이트 상세 페이지에 한 번에 표시되는 부분과 직접 제공된 1화, 사이트 링크에서 발견되는 다음 화로 제한됩니다. 3~1199화 등 중간의 전체 회차 탐색은 아직 구현하지 않았습니다.
- 챕터 페이지에 삽입된 일러스트 이미지는 이 단계에서 별도 렌더링하지 않습니다.
- 글자 렌더링은 흰 배경과 기본 한글 글꼴의 고정 크기이며, 실시간 폰트 크기 설정은 지원하지 않습니다.
- 19금 회차가 포함될 수 있으므로 확장 메타데이터에는 NSFW 표시가 포함되어 있습니다.

## GitHub Actions로 APK 빌드

빌드용 저장소 이름은 예를 들어 **arcgrid-cache**로 하고 `Private`으로 만들어도 됩니다. 파일명/확장 이름에 `Korean Novel`이 들어가지 않도록 했지만, **소스 코드 안에는 원본 사이트 주소가 포함**됩니다. 파일명만 바꾸는 것이 사이트나 코드의 실제 용도를 완전히 숨기는 것은 아닙니다.

1. GitHub에서 새로운 빈 저장소를 만듭니다. `Private` 선택 가능.
2. **이 ZIP 내용물**을 저장소 최상위 경로에 올립니다. 최상단에서 `gradlew`, `app`, `api`, `.github`가 보여야 합니다. `.github/workflows/assemble.yml`도 함께 올려야 합니다.
3. GitHub → Actions → **Package** → **Run workflow**를 실행합니다. `main` 브랜치로 push해도 빌드가 트리거됩니다.
4. 성공하면 해당 Actions 실행 결과의 Artifacts에서 **px-cache-package**를 다운로드합니다. 그 ZIP 안의 `app-release.apk`가 설치할 파일입니다.
5. Tachimanga → Browse → Extensions → `+` → APK 파일 가져오기. 이전 `Korean Novel Demo`와 패키지명이 다르므로 별도 확장으로 나타납니다.
6. **Page Cache** → 샘플 작품 → `1화`를 열어 실제 한글 본문 이미지가 표시되는지 확인합니다. 목록에서 2화 링크가 발견되면 2화도 테스트합니다.

매번 GitHub Actions에서 새 테스트 서명으로 빌드할 수 있으므로 새 APK 설치가 거부되면 **기존 Page Cache 확장을 제거하고 다시 가져오기** 바랍니다. 이전 서재 데이터는 별도 백업을 권장합니다.

## 문제가 발생하면

- 회차 목록 로딩 실패: 웹페이지 접속 제한이나 구조 변경 가능성. Web View 확인.
- `No text region found` 또는 `Chapter body not found`: 본문 HTML 셀렉터가 사이트와 맞지 않음.
- `Rendered page is no longer in memory`: 이미지 캐시가 초기화된 것이므로 해당 회차 다시 열기.
- `Stub!`: 사용된 런타임 API를 추가 점검해야 함. 이전 2화 문제와 동일 원인이라고 단정할 수 없음.

## 파일

- `app/src/main/java/.../ArcBridge.kt` : 사이트 요청, 회차 목록, 본문 추출, 이미지 URL 인터셉터
- `.../GlyphMatrix.kt` : 한글 글리프의 래스터 비트 데이터 (폰트 파일 자체는 포함하지 않음)
- `.../PortablePng.kt` : PNG/zlib/CRC/Adler32 자체 구현
- `.../FlowPages.kt` : 텍스트 줄 바꿈과 페이지 나눔
- `.github/workflows/assemble.yml` : 빌드 워크플로

글리프 비트맵은 NanumGothic 글꼴로 제작했습니다. 글꼴의 재배포/파생 저작물 관련 라이선스 조건은 별도 확인해야 합니다. 이 프로젝트는 개인용 실험을 목적으로 작성했습니다. 콘텐츠 이용 시 저작권과 사이트 이용 조건을 확인하세요.
